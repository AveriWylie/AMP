## PrismarineJS minecraft-data

AMP generates selected runtime data from [PrismarineJS/minecraft-data](https://github.com/PrismarineJS/minecraft-data), pinned at commit `e8ff8ec779a48814c2fc5b8a0ba7c95b9bc05d6d`.

The generated files are:

- `protocol/packet_ids.json`
- `blocks/blocks_1.20.2.json`
